## Approval Gate

Before implementation begins, stakeholders should approve:

- the modular-monolith starting point and extraction strategy;
- tenant isolation and organization membership rules;
- identity, refresh-token, and invitation flows;
- the canonical photo-processing and storage lifecycle;
- event gallery privacy behavior;
- the initial billing provider and entitlement model;
- the Phase 1 scope in the development roadmap.
